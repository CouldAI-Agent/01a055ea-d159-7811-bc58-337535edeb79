# Essay Writer

A distraction-free, elegant writing application built with Flutter. Designed to help you focus on your thoughts and words, Essay Writer provides a clean environment for drafting essays, articles, and long-form content.

## Features

- **Distraction-Free Editor**: A minimalist writing interface that lets you focus on your content.
- **Live Word Count**: Keep track of your length targets with a real-time word counter.
- **Responsive Design**: Adapts beautifully to mobile devices, tablets, and desktop screens with a dynamic masonry-style grid.
- **Auto-Save functionality**: Changes are updated instantly to the local state as you type.
- **Dark & Light Mode**: Honors your system preferences for a comfortable writing experience in any lighting condition.

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Native `ListenableBuilder` and `ChangeNotifier`

## How to Run

1. Make sure you have Flutter installed (`flutter doctor`).
2. Clone this repository and navigate to the project directory.
3. Run the following commands:

```bash
flutter pub get
flutter run
```
